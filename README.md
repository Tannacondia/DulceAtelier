Dulce Atelier

Sitio de presentación para una pastelería artesanal ficticia, con catálogo de productos y carrito de compras. Su estilo combina tonos cálidos, tipografía serif y fotografías de repostería.

Tecnologías: HTML5, CSS3 y JavaScript vanilla.


Funciones:
- Presentación del atelier, historia, catálogo de productos e información de contacto.
- Carrito con agregado y eliminación de productos, ajuste de cantidades y cálculo del subtotal.
- Enlaces para preparar pedidos y consultas por WhatsApp.
- Diseño adaptable y menú compacto para pantallas pequeñas.
